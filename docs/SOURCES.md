## 发布前需要补齐

- 原始发布者与稳定 URL，原始文件、页码/题号、日期、hash。
- 原始题面与公布答案的双人复核，转载/转录差异和裁决记录。
- 题目、图片、答案以及可能涉及人物资料的明确使用和再分发许可。
- 版本冻结、去重、泄漏/污染检查，以及可公开字段边界。
- 有争议、无法核验、非单选或缺失题目的显式处理政策。

**软件开源许可不自动覆盖底层数据。** 即使某个上游仓库标注 MIT，也不能据此推断其收录的赛事原题、图片或答案均可再分发；在权利链条未明确前，本项目只发布链接、元数据与原创合成样例。
