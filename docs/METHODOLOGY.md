# 评测方法与准入门槛（v0.1）

## 1. 研究问题必须分开

本项目第一阶段拟研究：模型在固定输入条件下，能否选择与某些公开赛事答案相同的选项。这里的参照物是**发布的答案键**，不是已经独立验证的世界事实。

- **赛事答案一致性**：对照公开答案；必须注明答案核验状态。
- **规则推理**：给定明确、可执行且无歧义的规则，检验规则应用；应另外建立可自动复算的参照答案。
- **真实事件预测**：必须另有带时间戳的事前预测、独立事件证据、预注册目标/基线、排除条件和评价窗口。回顾已公开人生经历的选择题，不能替代前瞻验证。
- **合成管线自检**：只验证软件流程，不能推出命理能力。

不将不同轨道的结果相加形成对「算命能力」的笼统结论。程序的总体汇总仅为记账方便，正式结果须按轨道报告。

## 2. 数据发布前的逐题清单

1. **定位来源**：原始发布者、原始链接、发布日期、获取时间、文件 hash、页码/题号；锁定来源版本，不仅记录可变的 `main` 分支链接。
2. **核对原文与答案**：两人独立核对原图/原文，确认年份、题号、四个选项和公布答案；记录分歧、修订与裁决理由。原图不可读则保持待核验，不凭转载一致性宣称 gold。
3. **核对计数**：来源所述总量和实际获取量分别记录；缺题、取消题、复选/无标准答案题不得静默删除。
4. **去重与泄漏检查**：检查近重复题、跨年复用、题干含答案、讲解混入选项及训练集污染线索。
5. **权利与隐私**：区分代码许可与题目/图片/人物资料权利；确认数据再分发及送往模型服务的授权、隐私边界。必要时只保留来源链接与可公开元数据。
6. **冻结版本**：发布独立数据版本、题目 ID 映射、校验结果、内容 hash 和变更日志；冻结后再运行对比。

上述事项尚未完成。目前仓库没有任何已验证赛事题目；2022–2024 的 120 题只是基于来源描述的候选规模。

## 3. 评分政策

对于每个输入题目，恰好归入一个类别：

| 类别 | 定义 |
| --- | --- |
| `correct` | 去掉首尾空白后，回答为单个大写 A/B/C/D，且与答案键相同 |
| `incorrect` | 格式有效，但与答案键不同 |
| `invalid` | 其他字符串，包括解释、多选、小写、空串；不猜测意图 |
| `refused` | 预测标记 `status=refusal`，或文本精确为 `REFUSE`（去首尾空白） |
| `error` | 请求/响应协议失败，或导入预测显式标记 `status=error` |
| `missing` | 该题在预测文件中完全没有记录 |

主指标 `accuracy = correct / total`，其中 `total` 包含以上全部类别。辅助指标 `answer_coverage = (correct + incorrect) / total`。不将无效、缺答、拒答或错误从分母中剔除，也不以「只算有效回答」的准确率替代主指标。

输出总体、逐年、逐轨道计数及逐题类别。跨行重复 ID 或预测中的未知 ID 直接使输入失败，避免不明确的覆盖/合并。年份来自题目记录，不能由预测文件自行改变。

四选一均匀随机选择的期望一致率为 25%，但这不是一切数据集上的充分基线：还应报告标签分布与多数类基线。合成样例的 50% 是人为设置的测试结果，不能作为模型评测成绩。

拒答识别有明确局限：只有协议字段或约定 token 计入 `refused`，自由文本中的「无法回答」计入 `invalid`。若将来增加语义拒答判定，须独立版本化和报告，不回溯静默更改成绩。

## 4. 公平对比与可复现性

每次运行保留：数据 SHA-256、请求模型标识、端点、提示版本与系统提示、温度、输出 token 上限、超时、开始/结束时间、请求数量、错误类别和逐题输出。不保存密钥、HTTP 请求头或错误响应正文。

先冻结：模型列表、模型版本、预算上限、提示、样本、重复次数、参数可比性与失败处理政策，再运行。暂未决定这些配置，不发布排行榜。没有实际模型调用或费用发生的验证。

当前 runner 单轮、无工具、无检索、无 few-shot、每题单次请求；不自动重试。不同提供方对 `max_tokens`、温度和推理 token 的解释可能不同，不能声称仅凭同名参数已经公平。请求名称可能映射到可变后端；即使温度为零也不保证确定性。当前没有成本估算、并发、断点补跑或服务端版本认证。

若需重复采样，使用独立运行目录并报告所有重复，而非选择最好的一次。较小年度样本不宜过度排名；正式分析应报告不确定性及配对比较，并预先约定方法。本 scaffold 尚未实现统计显著性检验。

## 5. 污染与答案记忆风险

公开题目和答案可能已经进入训练语料、搜索索引或提示缓存。高一致率可能来自答案记忆，不能直接推断推理能力。不能仅凭题目年份晚于某个声称的训练截止日期就断言「无污染」。

建议在获得授权后建立不公开答案的独立保留集，并区分原题、释义题、反事实改动题和新规则题；所有改写必须人工核对，防止改变答案或难度。真实未来预测更需要事前注册和时间隔离，而不是对公开历史案例做后验解释。

## 6. 不适用范围

不用于医疗、投资、法律、招聘、婚恋等高风险个人决策；不根据合成样例或赛事题表现宣称超自然能力真实有效。涉及人物的真实信息须在授权、去标识化与最小化原则下另行处理。
